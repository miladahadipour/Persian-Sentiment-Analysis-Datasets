# SnappFood Sentiment Dataset

Over 70,000 Persian user reviews from SnappFood, annotated as positive (HAPPY) or negative (SAD).

## Files
- `SnappFood.csv` — Main dataset file

## Columns
| Column | Description |
|--------|-------------|
| text   | Review text in Persian |
| label  | 0 = Negative, 1 = Positive |

## Source
[Kaggle - SnappFood Persian Sentiment](https://www.kaggle.com/datasets/soheiltehranipour/snappfood-persian-sentiment-analysis)
