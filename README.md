# Persian Sentiment Analysis Datasets

This repository contains the datasets used in the paper:

**A Two-Phase Linguistically-Enriched Transformer Framework for Persian Sentiment Analysis: Integrating Data Augmentation and Feature Fusion**

## 📁 Datasets

| Dataset | Description | Samples |
|---------|-------------|---------|
| [SnappFood](data/snappfood/) | In-domain food delivery reviews | 70,000+ |
| [DigiKala](data/digikala/) | Cross-category product reviews | 53,082 |
| [Insta-MultiDSenti](data/insta_multidsenti/) | Out-of-distribution Instagram comments | 18,182 |
